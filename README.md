## Run it locally

1. Download or clone this repository.
2. Double-click `index.html` to open it in your browser. No installation is needed.

## Publish with GitHub Pages

1. Make sure the main file is named exactly **`index.html`** and sits in the root of the repository.
2. Make sure the repository is **Public**.
3. Go to **Settings → Pages**.
4. Under "Build and deployment", set Source to **Deploy from a branch**, choose **main** and **/ (root)**, then click **Save**.
5. Wait 1 to 10 minutes. The live link appears at the top of the Pages settings screen.

> Tip: name the repository `YOUR-USERNAME.github.io` to get the shorter link `https://YOUR-USERNAME.github.io`.

## Updating the site

Upload a new `index.html` to the repository and commit it. GitHub Pages updates the live site within a couple of minutes.
